# Home Time: native iPhone app with Live Activity (dormant)

This project is **dormant**. It's a planned native iPhone app that shows your next journey home on the
lock screen and in the Dynamic Island, updating live.

Nothing is built yet. Start with [`HANDOVER.md`](HANDOVER.md), which has the full context: the goal,
what already exists in the web app to reuse, data quirks we've already discovered, the proposed design,
risks, prerequisites and a step-by-step plan.
